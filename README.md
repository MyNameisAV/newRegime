# WhichRegime — whichregime.in

India income-tax regime comparison tool. Vite + React + Tailwind v4.

## Commands
- `npm install` — setup
- `npm test` — engine test suite (must pass before any deploy)
- `npm run build` — outputs deployable `dist/` (upload contents to Hostinger public_html)

GA4 Measurement ID G-HTTBTG5K35 is wired in index.html.
